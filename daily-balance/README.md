# Daily Balance

Personal habit tracker. Open `index.html` to preview on a computer.

## Install on Android
1. Put the files online (see below) so you have an https:// address.
2. Open the address in Chrome on your phone.
3. Chrome menu (three dots) > "Add to Home screen" / "Install app".

## Putting it online (free)
- Easiest: https://app.netlify.com/drop - drag the whole folder in and you get a link.
- Later: GitHub Pages.

## Customise
- Water goal: `WATER_GOAL` at the top of app.js
- Mantras and journal prompts: the `MANTRAS` and `PROMPTS` lists in app.js
- Habits: the `HABITS` list in app.js

After changing any file, bump the version in sw.js (`daily-balance-v1` -> `v2`).
